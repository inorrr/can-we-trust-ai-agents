## Use in Google Vids

Upload the corresponding PNG to each scene. Set it to fill the 16:9 frame and extend its duration to cover the narration. Keep captions away from the main subject; add a gentle pan or zoom only if useful. Use the approved narration and retain the video's source information. Disclose that the conceptual scene illustrations were AI-generated.

The contact gallery is `index.html`. The exact generation prompts are saved in `prompts.json`. Original generated images are copied into this project without modification. Video rendering and publishing are separate steps.
